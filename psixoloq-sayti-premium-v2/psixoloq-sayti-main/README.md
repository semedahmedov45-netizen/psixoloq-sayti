# Psixoloq Premium — yenilənmiş versiya

Bu versiya əvvəlki statik layihənin daha müasir, mobil uyğun və funksional variantıdır.

## Yeni imkanlar
- Premium responsive dizayn və dark mode
- AZ / EN / RU dil dəstəyi
- Xidmətlər, proses, statistika, məqalələr, rəylər və FAQ
- Məqalə modalı
- Konsultasiya müraciət formu
- Müraciətlərin admin panelində siyahısı
- Xidmət/məqalə/rəy/FAQ idarəsi
- WhatsApp floating düyməsi
- Sadə SEO / Open Graph meta məlumatları

## Vacib qeyd
Bu layihə tamamilə statik işləyir. Konsultasiya müraciətləri brauzerin `localStorage` yaddaşında saxlanılır. Bu, real server bazası deyil.

Real istifadə üçün növbəti mərhələdə Supabase/Firebase və ya Netlify Functions qoşulması, həmçinin real admin autentifikasiyası tövsiyə olunur.

## İstifadə
`index.html` faylını Netlify-ə deploy etmək kifayətdir. Admin panel `admin.html` ünvanındadır.
