- Xidmətlər 4-dən 6-ya genişləndirildi.
- Məqalələr 4 nümunə ilə tamamlandı.
- FAQ 4 sual ilə tamamlandı.
- Professional profil təqdimatı gücləndirildi.
- Məxfilik/fərdi yanaşma/rahat format etibar göstəriciləri əlavə edildi.
- Konsultasiya forması saxlanılır və WhatsApp mesajı hazırlayır.

- Mobil və accessibility detalları yaxşılaşdırıldı.
- `localStorage` məlumatları üçün daha təhlükəsiz merge mexanizmi əlavə edildi.

## Vacib
Bu layihədə real server/database hələ yoxdur. Konsultasiya müraciətləri brauzerin `localStorage`-ında saxlanılır. Production üçün növbəti mərhələ Supabase/Auth + database inteqrasiyasıdır.

## GitHub/Netlify
1. Əvvəlcə GitHub-da backup branch yaradın.
2. Bu ZIP-dən çıxan `psixoloq-sayti-main` qovluğunun məzmununu repository-nin uyğun qovluğuna yükləyin.
3. Commit edin və Netlify deploy-un tamamlanmasını gözləyin.
