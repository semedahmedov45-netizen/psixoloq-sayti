# Psixoloq Premium Template

Hazır psixoloq sayt şablonu.

## Xüsusiyyətlər
- Responsive: mobil, planşet və kompüter
- Açıq zümrüd yaşıl + ağ dizayn
- Gündüz / gecə modu
- Azərbaycan, İngilis, Rus dilləri
- Kod yazmadan məzmun dəyişmək üçün Admin Panel
- Şəkil, məqalə, xidmət və FAQ redaktəsi
- WhatsApp və sosial şəbəkə linkləri
- Demo məlumatları localStorage-da saxlanılır

## İşə salmaq
1. `index.html` faylını açın və ya VS Code Live Server istifadə edin.
2. `admin.html` səhifəsinə keçin.
3. Məlumatları dəyişin və "Dəyişiklikləri yadda saxla" düyməsinə basın.

## Satış üçün vacib qeyd
Bu paket demo/admin-template versiyasıdır. Müştərinin dəyişikliklərinin bütün cihazlarda və internet üzərindən saxlanması üçün Firebase/Supabase kimi backend əlavə etmək lazımdır. Bu mərhələdə məlumatlar brauzerin localStorage yaddaşında saxlanır.
